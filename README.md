# Comment travailler proprement
## Lire la base du repo*
- Utiliser `tree` pour explorer la structure
- Consulter les documents `.md` en premier
- Puis examiner le code
- Noter dans la mémoire ce qui en est compris
- Noter dans la mémoire ce qui doit être fait, ce qu'il manque, les erreurs, problèmes, et ce qui pourrait l'impacter
- Proposer une idée et comment la modification serait, comment elle résoudrait le soucis, et des exemples détaillés et reliés au code actuel
- Valider et implémenter l'idée
- Tester, que ce soit en compilant, lançant en local, etc
- Vérifier la différence avec la version précédente et chercher toute erreurs potentiel
