# Recherche internet avant de réfléchir
- **Règle générale** : Avant toute réflexion sur une tâche, faire des recherches internet via le tool dédié sur **TOUTS les sujets possibles** liés à la demande
- **Chaque recherche doit couvrir :**
  - La tâche demandée elle-même (fonctionnement attendu)
  - Tout ce qu'il y a autour (contexte, écosystème, alternatives)
  - Comment c'est censé marcher (principes, mécanismes, bonnes pratiques)
  - La documentation en ligne officielle
  - Les repos GitHub pertinents (code de référence, issues, discussions)
- **POURQUOI ?** Pour éviter les erreurs d'interprétation et s'appuyer sur des informations à jour et fiables
- **QUAND ?** À chaque début de tâche, avant de coder ou de répondre
- **COMMENT ?** :
  1. Utilisez le tool `websearch` pour effectuer la recherche internet (voir doc en /skills/internet.md)
  2. Consultez aussi les sources internes (docs, code, repo local si pertinent)
- **ET** : METTRE A JOUR LA MÉMOIRE DU JOUR systématiquement
- **ET** : UTILISER bash-check pour valider les scripts shell avant exécution
