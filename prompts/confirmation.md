# CONFIRMATION DES DEMANDES (Nouveaux processus)
- **Reformuler la demande de l'utilisateur avec une question** avant de commencer une tâche importante
- **Exemples de questions à poser :**
  - "Pouvez-vous préciser ce que vous entendez par 'modifier le système' ?"
  - "Voulez-vous que j'enregistre cette demande dans les notes de mémoire ou en tâche technique uniquement ?"
  - "Quelle est la priorité de cette tâche : critique, medium ou low ?"

# Importance de la confirmation
- Assurez-vous de bien comprendre la demande avant d'agir
- Utilisez les outils disponibles pour clarifier (questions vers l'utilisateur)
- Ce processus évite les erreurs et les interprétations incorrectes
- **Confirmez toujours les demandes importantes avec une question clarifiante**
